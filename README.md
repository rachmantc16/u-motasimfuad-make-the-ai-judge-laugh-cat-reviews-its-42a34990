A single-line one-star review written by a house cat about its human owner, at most 200 characters, keeping the deadpan shape of a real review while the complaints go somewhere only a cat would go. Running the program writes the review to `/output/entry.txt` with no trailing newline.

## Run it

```sh
node main.ts
```
